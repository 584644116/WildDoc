# Word文档生成器使用指南

## 1. 简介
Word文档生成器是一个用于批量生成Word文档的工具。它可以根据Word模板和Excel数据文件，自动生成多个Word文档。

## 2. 功能特点
- 支持Word模板中的占位符
- 支持Excel数据导入
- 支持字段映射配置
- 支持字段类型验证
- 支持必填字段验证
- 支持批量生成文档

## 3. 使用步骤

### 3.1 准备模板
1. 创建Word模板文件
2. 在需要填充数据的位置使用[字段名]格式的占位符
3. 保存模板文件

### 3.2 准备数据
1. 创建Excel数据文件
2. 确保Excel文件包含所需的数据列
3. 确保数据格式正确

### 3.3 配置映射
1. 选择Word模板文件
2. 在配置对话框中设置字段映射
3. 设置字段类型和必填项
4. 保存配置

### 3.4 生成文档
1. 选择Excel数据文件
2. 选择输出目录
3. 点击"生成文档"按钮
4. 等待生成完成

## 4. 注意事项
- 确保Word模板中的占位符格式正确
- 确保Excel数据文件中的列名与映射配置匹配
- 必填字段不能为空
- 数字字段必须是有效的数字
- 日期字段必须是有效的日期格式

## 5. 常见问题

### 5.1 生成失败
- 检查模板文件是否正确
- 检查Excel数据是否完整
- 检查字段映射是否正确
- 查看错误日志获取详细信息

### 5.2 数据验证失败
- 检查必填字段是否有空值
- 检查数字字段是否包含非数字值
- 检查日期字段是否为有效日期

### 5.3 配置问题
- 确保所有字段都已映射
- 避免多个字段映射到同一个Excel列
- 保存配置后重新加载
